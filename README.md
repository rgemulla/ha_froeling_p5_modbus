# Froeling P5 Modbus Integration for Home Assistant

Based on the [Lambdatronic Modbus integration from
GyroGearl00se](https://github.com/GyroGearl00se/ha_froeling_lambdatronic_modbus),
adapted to the newer Lambdatronic 5000 control with one P5 boiler, one buffer,
one storage, and one heating circuit.
